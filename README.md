# Оно тебе надо

Статическая страница аукциона вещей, в которые никто не верил. Учебный проект Яндекс Практикума: семантическая разметка, Flexbox, Grid и позиционирование.

Для просмотра откройте `index.html` в браузере. Шрифты и изображения подключены локально.

Репозиторий: https://github.com/ursu-nikita/ono-tebe-nado-ad
